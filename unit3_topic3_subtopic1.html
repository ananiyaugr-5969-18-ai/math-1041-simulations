The Squeezing (Sandwich) Theorem

Prediction Prompt: Before moving the slider: If the upper function g(x) and the lower function h(x) both approach 1 as x approaches 0, what does this tell you about the middle function f(x), even if f(x) oscillates infinitely?
Function Formula Value at x
g(x) (Upper) x² + 1 1.250
f(x) (Squeezed) x² sin(8/x) + 1 1.189
h(x) (Lower) -x² + 1 0.750
Note how h(x) ≤ f(x) ≤ g(x) is satisfied at every point. As x → 0, the gap between g(x) and h(x) closes, forcing f(x) to approach 1.
